# ランチャー HUD

Launcher は、混雑した Windows タスクバーを補完するコンパクトなアプリ／リソースランチャーです。構造の編集は設定画面、起動やウィンドウ操作は HUD という境界を保ちます。

## ページ・グループ・アイテム

**設定 → HUD設定 → ランチャーHUD → ページとアイテム**を開きます。ページは順序付きのグループを持ち、グループは順序付きのアイテムを持ちます。ID は表示名から独立しているため、名前変更やターゲットの再指定でも同じアイテムとして保持されます。

Win32 アプリ、Microsoft Store を含むパッケージアプリ、ファイル、フォルダー、HTTP/HTTPS URL を登録できます。インストール済みアプリ、実行中アプリ、ファイル／フォルダーピッカー、URL 入力、Explorer から設定画面へのドロップに対応します。ドロップ後は保存前にアイテム編集画面を表示します。アイテムごとにカスタム画像／アイコンも指定できます。

通常の HUD では並び替え、名前変更、削除、移動、ピン解除を行いません。コンテキストメニューから、起動、個別ウィンドウ切替、通常の終了要求、確認付き強制終了、新規インスタンス、対応する Win32 アプリの管理者実行、ファイルの場所、設定での編集を利用できます。

見つからないターゲットは自動削除されず、復旧可能な状態で残ります。設定の**場所を指定…**でアイテム ID を変えずに更新するか、明示的に削除します。

## 表示と検索

Peek は現在ページの優先アイテムを最大 7 個表示し、空きがあれば Smart 候補を続けます。Expanded と Pinned ではページ選択、検索、グループ、アイテムグリッドを表示します。展開中に入力すると検索に入り、上下キーで選択、Enter で起動、Escape で解除します。検索対象は登録アイテムと非同期読み込みされるインストール済みアプリで、任意のファイル検索や Web 検索は行いません。

停止中のアプリはクリックで起動します。実行中なら直近に使ったトップレベルウィンドウを復元して前面化します。Shift+クリックは新規起動を要求しますが、単一インスタンス制約を持つアプリの最終動作はそのアプリに従います。

## Smart とプライバシー

Smart は、減衰する使用時刻、起動頻度、前面表示時間、時間帯との相性、前面アプリの文脈から、説明可能なローカルスコアを計算します。表示済みアイテムや見つからないターゲットは除外し、履歴量には上限があります。

使用データは `%LocalAppData%\NoraBar\Launcher\usage.json` のみに保存されます。Launcher の利用状況は送信されず、テレメトリーも追加しません。保存は間引かれ、**Smart → ランチャーの使用履歴を消去**でローカル履歴を削除できます。

## ルール

ルールは、曜日、時間帯、前面アプリの任意条件から有効ページを選びます。1 つのルール内は AND 条件です。優先度が高いものを採用し、同じ優先度では設定順が決定順になります。ルールはページ、グループ、固定アイテムを書き換えません。展開中に手動選択したページを優先し、折りたたみ後または次回展開から自動評価を再開します。

## グローバルショートカット

**ランチャーを開く**と**ランチャー検索を開く**は初期状態では未割り当てです。修飾キー付きのキー操作だけを受け付け、他アプリとの競合時は以前の有効な登録を維持します。終了時にはすべて解除します。ショートカットによる展開も**フルスクリーン時に展開を無効化**を尊重します。

## インストール済みアプリと Windows 固有動作

インストール済みカタログは専用 STA ワーカーで Windows のスタートメニュー／Shell ショートカットから遅延読み込みし、パッケージアプリのリンクも対象にします。同じ起動 identity は重複排除します。Win32 は実行ファイル identity、パッケージアプリは Windows が公開する場合に AppUserModelID を優先します。プロセスパスを隠すアプリ、別プロセス経由のパッケージウィンドウ、終了／新規起動要求を無視するアプリでは、最終動作は Windows と対象アプリに依存します。
